# SAHM Markets 💹

**SAHM Markets** is a modern trading-platform website concept designed to provide users with a clean, intuitive interface for exploring financial markets and managing a portfolio.

The platform combines a dark visual design with gold accents, account profiles, email verification, and customizable settings to create a streamlined trading-style experience.

## About the Project

SAHM Markets aims to bring essential account and portfolio features together in one place. The interface is designed around accessibility, simplicity, and a professional financial-dashboard appearance.


## Project Goals

SAHM Markets is designed to demonstrate how a trading-platform interface can combine account management, email verification, portfolio presentation, and user preferences in a single web application.

## Security and Limitations

SAHM Markets is a website project, not a licensed brokerage service. Real-money trading, live market data, secure server-side authentication, and persistent financial transactions require additional backend services and integrations.

Currency selection does not automatically convert balances using live exchange rates unless an exchange-rate provider is integrated.

Email verification requires valid EmailJS service, template, and public-key configuration.

## Disclaimer

This project is intended for educational and demonstration purposes. It does not provide financial advice or guarantee investment returns. Do not use it to manage real funds or credentials without appropriate security infrastructure.
